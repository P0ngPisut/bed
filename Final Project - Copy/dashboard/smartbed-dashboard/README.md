# Smartbed dashboard

หน้าเว็บเชื่อมต่อบอร์ดผ่าน USB Serial โดยตรง ไม่ต้องตั้งค่า MQTT หรือ broker

ตัวควบคุม A1–A4 ปรับทีละ 1 ระดับหรือกดค้างเพื่อขยับต่อเนื่อง โดยใช้เวลา 5 วินาทีต่อระดับ A2/A3 ใช้มอเตอร์พลิกตัวร่วมกัน ส่วน A4 แสดงระดับขาเทียบกับแนวราบ −7 ถึง +5: ระดับ 0 คือแนวราบ กด − เพื่อลดขาลง และกด + เพื่อยกขาขึ้น มอเตอร์ขาจะหมุนคนละทิศสำหรับการยกและการลด

A4 เมื่อแตะปุ่มปรับทีละระดับ ใช้เวลาเพิ่มอีก 2 วินาทีในขั้นสุดท้ายที่กลับระดับ 0 ทั้งจากทิศยกและทิศลด เพื่อชดเชยระยะที่ขาดเมื่อกลับแนวราบ

พนักพิง A1 ปรับได้ 0–8 ระดับ ท่านั่ง A5 ยังคงใช้พนักพิงระดับ 6 และเริ่มจากท่านอนราบเท่านั้น โดยขยับตามลำดับที่แสดงบนหน้าเว็บ: ขา 0→+1, พนักพิง 0→6, ขา +1→−3

A6 คือปุ่มปรับละเอียดสำหรับมอเตอร์เดิม เลือกพนักพิง พลิกตัว หรือส่วนขา แล้วกด +/− หนึ่งครั้ง บอร์ดจะขยับทิศที่เลือก 2 วินาทีแล้วหยุดเอง แม้หน้าเว็บขาดการเชื่อมต่อ คำสั่งนี้ใช้ปรับองศาแม้ระดับหลักอยู่ที่ขอบเขต เช่น ลดพนักพิงที่ระดับ 0 โดยไม่เปลี่ยนตัวนับระดับหลัก ใช้ปุ่มตั้งระดับอ้างอิงใหม่หลังปรับ actuator ให้อยู่ในตำแหน่งที่ต้องการ

เมื่อตั้ง actuator จริงให้อยู่ท่านอนราบแล้ว กด **ตั้งระดับปัจจุบันเป็น 0 (ไม่ขยับ)** เพื่อรีเซ็ตค่าตำแหน่งที่บอร์ดจำไว้โดยไม่สั่งมอเตอร์เคลื่อนที่ คำสั่งนี้ใช้ได้เฉพาะเมื่อบอร์ดรายงาน READY และอยู่ในโหมดควบคุมด้วยตนเอง ค่าภายในบอร์ดหลังตั้งใหม่คือพนักพิง 0, เอียง 5, ขา 5 ซึ่งหน้าเว็บแสดงเป็น 0 ทั้งสามส่วน

## เชื่อมต่อ

เปิด `index.html` ผ่าน Live Server ที่ `localhost` ใน Chrome หรือ Edge แล้วเลือกปุ่มตามบอร์ด:

- **เชื่อมต่อ ESP32 (115200):** เลือกพอร์ต COM ของ ESP32 เพื่อควบคุม Uno ผ่าน UART
- **เชื่อมต่อ Arduino Uno (115200):** เลือกพอร์ต COM ของ Uno เพื่อทดสอบและควบคุม Uno โดยตรง

เชื่อมต่อใช้งานทีละบอร์ดจากหน้าเว็บ หากต่อ USB กับ Uno โดยตรง ให้ถอดสาย TX/RX ระหว่าง Uno กับ ESP32 ก่อน เพราะ Uno ใช้ขา Serial 0/1 ร่วมกับ USB

ทั้ง USB Serial ของ ESP32, USB Serial ของ Uno และ UART ระหว่างบอร์ดใช้ 115200 baud

## อัปโหลดเฟิร์มแวร์

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\upload-smartbed.ps1 -Board ESP32 -Port COM4
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\upload-smartbed.ps1 -Board Arduino -Port COM6 -HoldEspPort COM4
```
