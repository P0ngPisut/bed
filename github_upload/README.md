# ESP32-S3 + โหลดเซล 20 kg

โปรเจกต์ PlatformIO สำหรับทดสอบโหลดเซลผ่านโมดูล HX711 บน ESP32-S3

## อุปกรณ์และการต่อสาย

โหลดเซลต้องต่อเข้ากับ **HX711** ก่อน ไม่ควรต่อโหลดเซลเข้าขา ESP32-S3 โดยตรง

**สำคัญ:** สำหรับโมดูล HX711 แบบ VCC เดียวที่ต่อ DT เข้ากับ ESP32-S3 โดยตรง ให้ต่อ VCC กับ **3V3** ไม่ใช่ 5V เพราะระดับ HIGH ของ DT อาจตามไฟเลี้ยง 5V และเกินระดับที่ขา GPIO ของ ESP32-S3 รับได้ ถ้าต่อ 5V อยู่ ให้ถอด USB ก่อนย้ายสายไฟ แล้วตรวจสายอีกครั้งก่อนเปิดเครื่อง

| HX711 | ESP32-S3 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| DT / DOUT | GPIO10 |
| SCK / CLK | GPIO9 |

ต่อสายโหลดเซลเข้าขา E+, E-, A+, A- ของ HX711 **ตามคู่มือหรือสีสายของโหลดเซลรุ่นที่ใช้** เพราะสีสายแต่ละรุ่นอาจต่างกัน หากใช้ GPIO อื่น ให้แก้ `HX_DOUT` และ `HX_SCK` ใน `src/main.cpp`

## เริ่มใช้งาน

1. เปิดโฟลเดอร์นี้ใน VS Code ที่มีส่วนขยาย PlatformIO IDE
2. ต่อ ESP32-S3 ด้วยสาย USB ที่รับส่งข้อมูลได้ แล้วเลือกพอร์ตของบอร์ด
3. กด **PlatformIO: Build** และ **PlatformIO: Upload**
4. เปิด Serial Monitor ที่ **115200 baud** (บางบอร์ดต้องเลือกพอร์ต USB/UART ให้ตรงกับการอัปโหลด)
5. ให้โหลดเซลว่างตอนเปิดเครื่องหรือส่งคำสั่ง `tare`
6. วางน้ำหนักที่ทราบค่า เช่น 1 kg แล้วส่ง `cal 1.0` ใน Serial Monitor พร้อม newline ค่าคาลิเบรตจะบันทึกไว้ในหน่วยความจำของบอร์ด

โปรแกรมแสดงค่าน้ำหนักต่ำกว่า 1,000 กรัมเป็น `g` เช่น `999 g` และตั้งแต่ 1,000 กรัมขึ้นไปเป็น `Kg` พร้อมเศษกรัม เช่น `1 Kg`, `1 Kg 250 g` พร้อมช่วงเทียบ ±5 กรัม และค่า ADC ดิบทุกประมาณครึ่งวินาที ช่วง ±5 กรัมยังแสดงเป็นกรัมและเป็นเกณฑ์เทียบ ไม่ใช่การรับรองความแม่นยำจริง ต้องทดสอบด้วยน้ำหนักอ้างอิง คำสั่ง `cal` และ `check` รับน้ำหนักเป็น **kg** เช่น 185 กรัมใช้ `cal 0.185` และ `check 0.185` หลังคาลิเบรต หากยังไม่คาลิเบรต จะแสดงจำนวน count แทน ถ้าบอร์ดเป็น ESP32-S3 รุ่นอื่น ให้ตรวจ `board` ใน `platformio.ini` ให้ตรงกับรุ่นก่อนอัปโหลด

## ดู log และบันทึกค่า

เปิด Terminal ใน VS Code แล้วรัน `.\monitor.cmd` เพื่อดูค่าจาก COM3 แบบต่อเนื่องพร้อมเวลา และบันทึก CSV ที่ `logs/loadcell_g_5g.csv` กด Ctrl+C เพื่อหยุด หากพอร์ตเปลี่ยน ใช้ `.\monitor.cmd --port COM4` ปิด PlatformIO Serial Monitor หรือโปรแกรมอื่นที่จับพอร์ตอยู่ก่อนรันคำสั่งนี้ ไฟล์ `logs/loadcell.csv`, `logs/loadcell_g.csv`, `logs/loadcell_kg_int.csv` และ `logs/loadcell_g_10pct.csv` เป็น log รูปแบบเดิม

ไฟล์ CSV มีคอลัมน์ `timestamp`, `weight_g`, `band_min_g`, `band_max_g`, `net_counts`, `raw`, `message` โดย `weight_g` เก็บเป็นกรัมจำนวนเต็มเสมอ แม้จอแสดงเป็น Kg ก่อนคาลิเบรต `weight_g` จะว่างและ `message` จะเป็น `uncalibrated` ขณะตัวบันทึกทำงาน พิมพ์ `tare` แล้ว Enter เมื่อโหลดเซลว่าง จากนั้นวางน้ำหนักที่ทราบค่า เช่น 1 kg แล้วพิมพ์ `cal 1.0` แล้ว Enter เพื่อคาลิเบรต หากต้องการตรวจเกณฑ์ ±5 กรัม ให้วางน้ำหนักอ้างอิงอีกชิ้น แล้วพิมพ์ `check 1.0` สำหรับน้ำหนักอ้างอิง 1 kg โปรแกรมจะแสดง `PASS` เมื่อความคลาดเคลื่อนไม่เกิน 5 กรัม และ `FAIL` เมื่อเกิน 5 กรัม

หากเห็น `HX711: no conversion wait` แปลว่าขา DT ไม่แสดงจังหวะแปลงข้อมูลของ HX711 โปรแกรมจะไม่แสดงค่าน้ำหนักในสถานะนี้ ให้ตรวจ DT→GPIO10, SCK→GPIO9, VCC→3V3, GND→GND และสายโหลดเซลที่ E+/E-/A+/A- ก่อนคาลิเบรต หากย้าย VCC เป็น 3V3 แล้วยังขึ้นข้อความเดิม ให้ส่งรูปการต่อสายและรูปโมดูล HX711 เพื่อระบุจุดผิดพลาดต่อไป
